## Model-to-code limits

The baseline counterexamples and post-fix status for AP-1 through AP-8 are recorded in [POLICY_AUDIT.md](POLICY_AUDIT.md). The post-fix claims use local tests for code correspondence and Lean only for the stated abstract predicates.

Lean checks the abstract predicate and transition definitions in `proof/Model.lean` and `proof/PolicyAudit.lean`; it does not compile or import Go, TypeScript, or SQL. The generalized list-filter theorem reports Lean's standard `[propext, Quot.sound]` axioms; the concrete guard and counterexample theorems report no axioms. Local tests provide separate implementation evidence. Neither establishes the source service's current page semantics, production rollout state, or that every deployed writer uses the new migration and guard. See [PROOF_REPORT.md](PROOF_REPORT.md) and [PRODUCTION_TEST_PLAN.md](PRODUCTION_TEST_PLAN.md).

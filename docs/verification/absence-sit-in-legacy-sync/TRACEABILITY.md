## Model-to-code limits

Lean checks the abstract predicate and transition definitions in `proof/Model.lean`; it does not compile or import Go, TypeScript, or SQL. Local tests provide separate implementation evidence. Neither establishes the source service's current page semantics, production rollout state, or that every deployed writer uses the new migration and guard.

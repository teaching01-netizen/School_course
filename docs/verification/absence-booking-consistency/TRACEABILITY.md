## Adversarial traces

- Two requests can reach the same idempotency key. Only a fresh journal key can publish in the model. The dedicated local race test observed one durable absence.
- A commit may succeed while its response write fails. Sixteen concurrent retries across two local HTTP handlers with independent pools returned byte-identical bodies and retained one absence, one make-up assignment and one missed-session link.
- The invalid second item of a batch can run after the first item's writes have been staged. The local rollback test verified that the first item's writes did not persist.
- The policy can change between validation and commit. An HTTP policy update returned 200 while the booking's COMMIT was paused. After release, the booking returned 201 and the assignment existed. The result refutes the stronger commit-time eligibility claim.
- PostgreSQL failover, browser version skew, key expiry and throughput under sustained contention remain outside this execution evidence.
